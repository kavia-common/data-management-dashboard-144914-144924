# Frontend Scripts Notes

This container provides the React UI. It must not be used to run the backend preview.

- Run frontend dev server from this directory:
  data-management-dashboard-144914-144924/mongodb_dashboard_frontend

- Scripts:
  - npm start (React dev server on port 3000)
  - npm run build
  - npm test

The backend runs separately on port 3001 from the backend container. Ensure API base URLs point to the backend.
